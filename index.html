Create race result data, preview it live, and generate a self-contained embed link.

Getting started
  1. Import existing data — paste a previously generated embed link (or just its data= value) into the Import box to load races back into the form.
  2. Enter data from scratch — click "+ Add Race", fill in race names and candidates, and adjust vote shares and % counted as results come in.
  3. Preview live — the right-hand panel updates as you type so you can see exactly how the results will look.
  4. Export an embed link — copy the generated <iframe> snippet from the Embed Link panel and paste it into any page. The data is encoded directly in the URL — no CSV file, hosting, or server needed.
