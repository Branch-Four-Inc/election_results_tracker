Copy this code into your website

Paste it into a “Custom HTML” block on your page or post.

How to paste it in WordPress
  1. Open the post or page in the editor and click the + button to add a block.
  2. Search for and choose Custom HTML.
  3. Paste the code you copied, then click Preview to check it.
  4. Publish or update the post.
How to paste it in Ghost
  1. In the editor, type /html on a new line (or click + and choose HTML).
  2. Paste the code you copied into the HTML card.
  3. Click outside the card to see the widget, then publish or update.
Squarespace, Wix, Substack and others
  1. Add an Embed, Code or Custom HTML block.
  2. Choose the option to paste HTML or embed code (not a plain link).
  3. Paste the code and save.
Results changing? The widget shows the numbers as of right now. When counts update, use Back to edit (or paste your old code into “Already made a widget? Edit it” on Step 1), then copy the new code and replace the old one on your site.
